# 📊 Classificador de Indicação

Projeto simples em HTML, CSS e JavaScript que classifica uma nota de 0 a 10 e exibe um feedback personalizado na tela, alterando também a cor da mensagem de acordo com o resultado.

👨‍💻 Autor

Pedro Oliveira

📌 Descrição

O sistema permite que o usuário digite uma nota de 0 a 10.
Ao clicar no botão "Analisar Nota", o programa classifica a nota e exibe uma mensagem correspondente:

Nota	Classificação	Mensagem
9 - 10	Excelente	Recomendado para todos
7 - 8	Bom	Recomendado para a maioria
5 - 6	Regular	Pode ser recomendado com ressalvas
0 - 4	Ruim	Não recomendado
Fora do intervalo	Inválida	Digite um número entre 0 e 10

Além da mensagem, a cor do texto muda dinamicamente para representar visualmente o resultado.

🎨 Interface

Tema escuro

Layout centralizado

Caixa com efeito de sombra

Estilo moderno e minimalista

Feedback com cores diferentes para cada classificação

🛠️ Tecnologias Utilizadas

HTML5

CSS3

JavaScript

🚀 Como Executar

Salve o arquivo com a extensão .html

Abra o arquivo em qualquer navegador moderno

Digite uma nota entre 0 e 10

Clique em "Analisar Nota"
